Investigation Summary

Our investigation confirms that the viral footage circulating on major social networks, which purported to show ballot stuffing at polling station #42, is a manipulated composite. The footage combines elements from a 2018 municipal election in a different region with recently fabricated audio.

Key evidentiary points include:

  • Geographic Inconsistencies: Architectural features visible in the background do not match the current structural layout of the claimed location.
  • Metadata Analysis: The source file metadata indicates a creation date predating the current election cycle by several years.
  • Audio Desynchronization: Spectrogram analysis reveals distinct anomalies where background noise cuts out unnaturally, suggesting audio track replacement.
